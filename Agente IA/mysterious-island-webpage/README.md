# Mysterious Island Webpage

This project is a themed webpage inspired by "The Mysterious Island" by Jules Verne. It features a visually appealing design and integrates a chatbot using Dialogflow Messenger for interactive user engagement.

## Project Structure

The project consists of the following files:

- **index.html**: The main HTML document that contains the structure of the webpage, links to the CSS file, and integrates the Dialogflow Messenger code for chatbot functionality.
- **css/style.css**: The CSS file that defines the visual theme of the webpage, including colors, fonts, and layout styles inspired by the novel.
- **README.md**: This documentation file that provides an overview of the project, setup instructions, and other relevant information.

## Setup Instructions

1. Clone the repository or download the project files.
2. Open the `index.html` file in a web browser to view the webpage.
3. Ensure that you have an internet connection to load the Dialogflow Messenger functionality.

## Features

- A visually engaging design that reflects the themes of adventure and mystery from "The Mysterious Island."
- Integration of a chatbot for user interaction, powered by Dialogflow.
